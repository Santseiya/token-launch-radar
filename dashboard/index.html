How the value is worked out

Every implied value comes from the snapshot's own figures — never from a hand-kept list of names. The same formula scores every protocol.

implied value = TVL × peer multiple × growth multiplier × maturity multiplier
  1. Peer multiple. The median market-cap-to-TVL ratio of the token-bearing protocols in the same category (at least 3 peers, else the global median), clamped to 0.05 – 1.50. A protocol in a richly-valued category is worth more than the same TVL in a thin one.
  2. Growth multiplier. 1 + clamped 7-day TVL change (−50% to +100%) × 0.6. A growing protocol is worth more than a shrinking one.
  3. Maturity multiplier. 0.7 + min(age in days, 1460) / 1460 × 0.5. A protocol that has run a long time with no token carries more pent-up launch value. Age unknown: 365 days.

What the board does not claim

A protocol on the board records no token in the snapshot — that is DefiLlama's record, not proof it has none. The board never predicts whether or when a token is issued; its implied value is this radar's own claim about what a launch would be worth if the protocol's record stayed as it is. The watchlist floor is $50,000,000 of TVL; the early rows below it are the radar's own finds.
